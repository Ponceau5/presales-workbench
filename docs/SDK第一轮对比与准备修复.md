# Agent SDK 第一轮本地验证

日期：2026-10-16。未连接或更新云服务器，尚未更换正式工作区执行引擎。

## 准备修复

- 文件分类改为 `(document_id, stage_id)` 联合主键，保留旧数据迁移。同一模板可被多个工作区引用。
- 上游保留所有成果版本，前端分组后默认展示最新版。
- 接通资料弹窗“用于本次任务”，预览和任务输入分别操作；替换版本时移除同一资料的旧版本引用。
- 模板用途查询限定当前工作区，避免其他工作区的分类影响当前任务。
- 人工采纳成果后生成默认下游通知，适用于不同项目；重复采纳不重复通知，不启动下游 Agent。
- 资料弹窗按后端存储模式选择普通上传或 OSS 签名直传；下载原件保留文件名，上游成果支持下载。

## 验证证据

- 24 项回归测试通过：18 项资料、权限和流程检查，5 项 SDK 边界检查，1 项成本流程检查。
- TypeScript 检查和 Vite 构建通过，构建仍提示已有前端包较大。
- 浏览器通过已有 Casdoor 会话登录本地工作台，进入 GSA02/F7，检查资料弹窗、V1/V2 预览、选择后显示“已选3页资料”、刷新后保留。测试选择已取消还原。
- 本地服务：前端 7101，后端 8000。

## 三种 SDK 实测

模型统一为智谱 glm-5.3-flash。每个场景同一提示词、同一输入、同一业务工具。工具为资料目录、资料读取和 Decimal 计算；不发布正式成果。

每个 SDK 每个场景一次，共15次有效真实调用：

1. complete：选择V2清单，使用计算工具得到195.00 CNY。
2. missing：缺少采购回价，不编造单价。
3. f5：阅读实际GSA02电气规范摘录，识别软件依据不足。
4. f8：识别客户“套”和内部“台”不能直接换算。
5. actual-f7：读取数据库中的F7成本Skill（2995字符）和实际演示参考资料的一页（4668字符），只进行资料摸排。

| SDK | 版本 | 基础4例检查 | 基础4例平均耗时 | 进程峰值 | 基础4例输入/输出Token | 实际F7摸排耗时 |
|---|---|---|---|---|---|---|
| LangChain | 1.4.6 | 4/4 | 20.39秒 | 105.6 MiB | 6478 / 673 | 26.06秒 |
| Pydantic AI slim | 2.56.0 | 4/4 | 20.26秒 | 88.3 MiB | 6720 / 708 | 26.29秒 |
| Strands Agents | 1.61.1 | 4/4 | 21.41秒 | 88.2 MiB | 6842 / 624 | 24.03秒 |

检查通过指工具调用与必要结果标记符合断言，不等于完整业务验收通过。实际回答保存在测试目录，仍需要人工业务评阅。

内存是macOS单个Python测试进程的峰值，不包含工作台后端、Casdoor、浏览器和大型文件解析。LangChain使用原服务环境，另外两家使用隔离测试环境；依赖不同。不能据此推算2GB Linux服务器的完整并发容量。

这是单次小样本，不同SDK的模型请求存在同时运行，受网络及供应商排队影响，不能据此作速度排名。Token是SDK转述的供应商字段，未核对推理、缓存和账单明细，未换算人民币。

## 观察到的问题

- Pydantic AI首次已给出正确答案，但测试脚本误用旧版 `usage()` 写法，新版为 `usage` 属性。修正度量代码后重跑，该无效记录不计入表格。
- Strands在实际F7测试中提示Chat Completions多轮不保留reasoningContent；可见回答成功，但后续要验证智谱对推理状态回传的要求。
- 实际F7回答有时会把默认倍数、默认参数依据列为待确认。需要明确演示和正式运行条件，验证默认参数何时可直接使用，不能仅凭“列出缺失”就判定业务合格。
- F5样本为电气SPD条款，测试的是“缺少软件依据”的边界，并未完成服务器规格全流程验证。

## 当前结论

三家均可进入实际工具集成验证。没有足够证据立即确定胜者。Pydantic AI和现有LangChain优先比较结构化参数、文件工具、取消和错误事件，Strands保留为对照。

正式服务依赖未新增Pydantic AI或Strands。最终只选择一个引擎，项目权限、资料版本和人工协作仍由工作台管理。

## 复现位置

脚本：`scripts/compare_agent_sdks.py`。

设置环境变量 `PRESALES_SDK_RESULTS` 指向含 `cases.json` 的测试目录，然后用对应SDK虚拟环境执行：

```sh
python scripts/compare_agent_sdks.py langchain complete
python scripts/compare_agent_sdks.py pydantic complete
python scripts/compare_agent_sdks.py strands complete
```

密钥只从本地配置或环境变量读取，不写入测试输出。
