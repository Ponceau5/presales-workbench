# 本地登录、退出与权限页修补

2026-10-16

- 删除连接设置菜单和页面；旧 /settings 地址返回首页。模型配置继续使用服务端配置。
- 权限管理缩小标题、页边距、表格行距、筛选器和详情抽屉间距；窄屏表格横向滚动。
- 显式退出先清除浏览器工作台凭证，再注销服务端当前会话，通过 Casdoor /api/logout 结束当前浏览器身份会话，使用已登记的 OIDC 回调地址返回工作台。
- 退出回调使用随机 state 和签名会话 Cookie 校验，不接受任意返回地址。未向前端暴露 client secret。
- 显式退出后设置重新认证标记；若退出请求网络失败，下次登录仍要求重新认证。普通进入应用时保留已有单点登录行为。
- API 返回 401 时清理失效凭证和工作台登录快照，回到登录页。
- 登录应用主标识使用 public/workbench-logo.svg 和暗色版本。本地 Casdoor 应用 admin/presales-workbench 已通过管理 API 更新 logo、logoDark、homepageUrl；该运行配置位于本地 Casdoor 数据库，云端未修改。

验收：12 项身份认证测试、34 项权限/流程测试通过；TypeScript 检查与生产构建通过。浏览器验证退出后回到登录页，再次登录出现账号密码表单；未修改账号、岗位或项目授权。
