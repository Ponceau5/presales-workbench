## 业务边界

执行器只提供已引用资料目录、版本快照正文、当前参数、同币种明细金额计算四种工具。每次工具调用重新校验项目权限；工具不能切换项目、查询任意文件、发布、采纳或发送通知。资料在本次执行开始时复制为快照，不会中途变成最新版本。正式发布和下游通知仍通过人工采纳的业务接口。

公共问答与 Skill 试运行继续使用原流式事件协议。工具轨迹随回复 sources 保存；F5 旧入口记录到现有审计中。无需新数据库迁移。模型异常不直接暴露供应商原始响应。原有智谱至 DeepSeek 的备用策略保留连接失败和 502/503 场景，且只在尚无文本、尚未执行工具时切换，避免重复执行。其余失败明确停止，不自动重跑任务。

执行上限：每任务最多 5 次模型调用、8 次业务工具调用；每进程最多同时运行 2 个共享执行任务。单次模型连接超时 60 秒，循环在收到事件时检查 180 秒预算；这不是进程级强制中断机制。

F7 原有持久化执行记录继续保留，未扩展到其他岗位。其他岗位采纳成果不再调用 F7 的恢复流程。
