# Agent SDK 本地验证

## 结论

LangChain `create_agent` 可以连接当前智谱 glm-5.3-flash，并自动执行工具调用循环。首次真实测试已完成：模型自行选择资料目录、读取正文、计算金额，然后返回195.00 CNY的小计。不是在后端预先写死这三个工具的执行顺序。

这是独立、只读的本地试验接口，没有替换现有F7快捷入口，没有扩展手工编排的LangGraph流程，没有修改云服务或正式成果。

SDK本身底层使用LangGraph；这不要求业务必须设计暂停、人工审批或断点恢复。此次使用 `create_agent` 默认循环，不添加检查点或人工确认节点。

## 实测

模型：本地已经配置的智谱 glm-5.3-flash，未更换供应商。

输入：合成测试清单V1，设备A数量6、成本单价12.50 CNY；设备B数量4、成本单价30.00 CNY。没有发送真实项目原件。

使用当前F7成本Skill作为指令，让模型只核对材料小计。

实际调用：
1. `list_selected_materials` 获取文档ID和允许页码。
2. `read_material_page` 读取已选页正文。
3. `calculate_line_totals` 使用Decimal计算75.00、120.00及合计195.00。
4. 模型返回结果与资料版本。

总耗时17.534秒，首次可见文字15.966秒。SDK返回的累计usage为输入13016 tokens、输出192 tokens。多轮请求会重复携带Skill与上下文，不能据此承诺SDK比原来一次调用更快或更省。

首轮验证的工具均已执行，但因SDK内部步数限制过低而未返回最终答案；已将内部步数上限调整为32，同时保留最多4次模型调用、8次工具调用。修正后的真实复测通过。

## 接口和限制

`POST /api/projects/{项目ID}/workspaces/F7/flows/sdk-trial-stream`

请求示例（文档ID必须来自该项目已上传、已解析的资料）：

```json
{
  "question": "读取已选清单，用计算工具核对材料小计",
  "task_id": "cost",
  "selected_pages": [{"document_id": "当前项目文档ID", "page": 1}]
}
```

可传 `flow_draft_id` 使用当前账号的个人Skill草稿；未传时使用该项目当前正式Skill。后端不会替模型预先选择读取或计算顺序。

- 仅F7销售或管理员可试运行；每次工具调用重新检查当前项目权限。
- 只能读请求中选定的文档页；不能读其他项目、任意本地路径或URL。
- 工具只读取资料/参数或计算数字；没有采纳、发布、发送、Shell或任意文件写入能力。
- 单次最多10个选定页，单页正文上限12000字，最多4次模型调用和8次工具调用；同一进程仅允许1次SDK试运行并发。
- 请求有网络超时和执行时间检查，但不能保证远端模型立即取消。
- SSE输出可见文字和工具完成事件，不显示隐藏思考内容。
- 试运行结果、工具名称、用量、耗时、Skill及其版本快照、选定页索引保存在工作台数据库 `sdk_trials`；不保存API Key。
- 当前只支持上传文档正文，尚未把所有上游成果、原成本模板生成和文件导出工具接入SDK。
- 当前参数工具读取Skill默认值，不覆盖项目参数；它尚未替代正式“资料与参数”功能。
- 当前SDK没有实现旧网关的自动备用模型切换；也未验证DeepSeek兼容性，后续应独立验证。

依赖：langchain 1.4.6、langchain-openai 1.7.2，锁定到已验证版本。没有额外部署平台或运行本地模型。

## 后续采用方式

优先将项目目录、上游成果和现有确定性计算/导出函数封装成受限工具，逐项验证后再让现有Skill“试运行”按钮调用SDK。普通任务不强制引入暂停和恢复；原有LangGraph执行路径保持独立，是否保留按业务需要决定。
