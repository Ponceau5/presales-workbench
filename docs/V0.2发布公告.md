# 售前项目工作台 V0.2 发布公告

V0.2 已上线，欢迎大家试用。这一版围绕“以项目为主线，把售前资料、专业处理、成果和变更连起来”进行更新，让资料查找、专业协作和经验复用更顺畅。

## 本次更新

**项目进度看得更清楚。** 首页围绕售前交付展示项目阶段、进展和最新跟进；项目内部提供流程、资料与工件、里程碑三个视图，方便了解当前做到哪一步、还有哪些事项需要处理。

**每个工作区都有可复用的工作方法。** F1–F13 的快捷入口配有可编辑的 Skill 示例，包含输入资料、处理步骤、可用工具、业务规则和输出要求。软件工作区补齐了资料摸排、功能清单、差距分析与澄清、服务器规格、内部成本等示例。快捷入口支持新增、改名和删除。

**资料和输出模板可以沉淀到项目中。** 支持上传本地文件、粘贴图片，并在“资料与工件”登记参考资料和工件模板。系统会检查重复文件，对适合保留的附件进行归档并提示。Skill 可引用已登记模板；Word、Excel 支持按匹配字段填充输出。

**项目助手更贴近实际协作。** 可询问项目状态、查找资料、描述客户需求变化，协助整理待跟进事项及变更建议。保存业务记录由用户确认；需要形成成果的工作流先出草稿，再由人核对采纳。

**试用入口和使用引导更完整。** 支持自行注册并选择角色，试用阶段默认“系统管理员”，可操作和管理所有工作区。首次进入会出现使用引导，之后可通过右上角手册图标查看当前页面说明；Skill 页面另有编写指南。

## 如何开始使用

工作台地址：**http://8.130.81.157/**

- 体验账号：**用户名 `pm`，密码 `demo2026`**。
- 也可通过注册入口自行创建账号：填写用户名、两次密码并选择角色。试用阶段默认系统管理员。

建议按以下顺序体验：

1. **先看项目监控。** 了解项目阶段和最新跟进，再进入“项目”列表。
2. **点击项目名称。** 进入项目流程，选择环节并打开工作区；左侧流程菜单也可直接进入对应工作区。
3. **准备项目资料。** 在“资料与工件”上传当前项目的清单、客户要求、BOQ 等；需要固定输出格式时，登记为“工件模板”。公司通用介绍、产品手册和通用参考资料放在“公共资料”。
4. **运行快捷工作流。** 点击对话框上方入口，或直接输入任务并上传附件。需要形成工件时，核对草稿后再采纳；资料摸排等查询类任务无需采纳。
5. **沉淀自己的 Skill。** 打开工作区的“Skill”，查看示例并修改目标、步骤、判断规则、参考资料和输出格式。先保存草稿、试运行，确认效果后应用，让后续任务复用这套做法。

工作台会话有效期为 **8 小时**，Casdoor 身份会话有效期为 **30 天**。同一浏览器未主动退出、未清除 Cookie 时，工作台会话过期后可通过“使用以下账号继续”重新进入；主动退出或身份会话过期后需重新验证。
