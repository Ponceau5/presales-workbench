# 售前项目工作台 V0.2

## 本次更新

- 项目监控：按售前阶段查看项目，展示最新跟进、成果与变更状态。
- 项目工作区：提供 F1–F13 快捷工作流，支持上传文件、粘贴图片和与 Agent 对话。
- Skill：补充各工作区示例，支持直接编辑处理步骤、规则和输出要求；快捷入口可新增、改名、删除。
- 资料与工件：可登记项目资料和工件模板，按项目查找和下载；需要输出成果的工作流支持核对后采纳。
- 项目助手：可查询项目资料与状态，整理客户需求变化和待跟进事项。
- 登录与引导：支持自行注册，首次进入显示操作指南，右上角手册图标可再次打开。

## 使用方法

**1. 进入项目。** 打开左侧「项目」，点击项目名称进入项目流程。点击流程环节的「打开工作区」，或点击左侧 F1–F13 菜单进入对应工作区。

![项目流程：选择环节并打开工作区](https://raw.githubusercontent.com/Ponceau5/presales-workbench/master/docs/images/v0.2/flow.png)

**2. 准备资料、运行任务。** 当前项目的清单、客户要求、BOQ 和输出模板，在顶部「资料与工件」登记。公司介绍、产品手册等通用资料在左侧「公共资料」查看。进入工作区后，点击输入框上方的快捷入口，或直接输入任务；回形针可上传文件，也可粘贴图片。需要形成工件时，核对草稿后点击「采纳结果」。

![工作区：快捷入口、上传文件和对话输入框](https://raw.githubusercontent.com/Ponceau5/presales-workbench/master/docs/images/v0.2/workspace.png)

**3. 修改 Skill。** 点击工作区右上角「Skill」。Skill 就是交给 AI 的操作流程：使用哪些资料、第一步做什么、遵守哪些规则、最后输出什么。可直接修改示例，保存草稿后试运行。需要固定格式时，先在「资料与工件」登记工件模板，再在 Skill 中写明模板名称和使用要求。

![Skill：编辑操作流程并试运行](https://raw.githubusercontent.com/Ponceau5/presales-workbench/master/docs/images/v0.2/skill.png)
